## Evidence hygiene

- [ ] Outputs are attributable to the exact commit and build.
- [ ] No API keys, unreleased transcripts or unredacted internal meeting material are attached.
- [ ] Real-hardware evidence is separate from controlled adapters/mocks.
- [ ] The tester listened to audio where audibility is part of the acceptance criterion.
- [ ] Every failing case has an issue link and a retest reference.
- [ ] The change did not regress a previously accepted scenario.
